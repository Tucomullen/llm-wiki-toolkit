# CLAUDE.md

This is a Markdown knowledge base maintained with `wikikit`. Follow `AGENTS.md` (same rules).

Quick reference:

- Read `_meta/INDEX.md`, then only the sub-indices you need in `_meta/index/`.
- Search with `wikikit search query "text"` before using grep.
- Log with `wikikit log append ENTRY.md`. Save sources with `wikikit raw save FILE`.
- Never edit `raw/**` or `_meta/LOG.md` directly (the example settings deny it).
- Finish with `wikikit verify --fail-on-broken`.

Copy `claude-settings.example.json` to `.claude/settings.json` to enforce the locks.

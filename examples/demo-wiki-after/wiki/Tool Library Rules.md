# Tool Library Rules

How members borrow shared tools.

Members may borrow tools for up to one week. Sign the loan book in the shed. Clean tools before returning them. Broken tools are reported to the treasurer.

The wheelbarrows and watering cans listed in [[Watering Schedule]] stay on site.
